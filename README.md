# PAISE Workshop Website

Official website for **PAISE (Parallel AI and Systems for the Edge)**, an annual workshop focused on advances in artificial intelligence, parallel and distributed computing, and systems for edge computing.

**Website:** https://paise.org/

## About

PAISE brings together researchers and practitioners working at the intersection of artificial intelligence, edge computing, distributed systems, and high-performance computing.

The workshop provides a forum for discussing emerging research challenges, innovative solutions, and practical experiences in developing intelligent systems at the edge.

## Website

This repository contains the source code and content for the PAISE workshop website.

The website is built using [Jekyll](https://jekyllrb.com/) and is based on the open-source [al-folio](https://github.com/alshedivat/al-folio) theme.

Workshop information, including calls for papers, important dates, programs, organizers, and previous editions, is maintained here.

## Local Development

To run the website locally, install Ruby, Bundler, and Jekyll, then execute:

```bash
git clone https://github.com/paise-org/paise-org.github.io.git
cd paise-org.github.io
bundle install
bundle exec jekyll serve
```

Open `http://localhost:4000` in your browser.

Some theme dependencies may require additional system packages.
